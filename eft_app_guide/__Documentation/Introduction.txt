-------------------- Comment Definitions --------------------
- DefinitionEntity
	An entity that purely defines the state and fundamental data.

- AggregativeEntity
	An entity that centralise associated/related entities within itself.

- JunctionEntity
	An entity to associate 2 or more tables through thier primary keys.

- AssociationEntity
	A JunctionEntity containing additional domain-specific data.


---------- Terms Used ----------
- Composite keys
	A primary key composed of multiple properties, often derived from foreign keys.

- PK / Primary key
	A unique identifier used to identify an entity in a relational database.

- FK / Foriegn key
	A key referencing another entity's primary key.

---------- Custom Objects & ValueObjects ----------
- AssociationList<>
	A Collection used to signal that the list consists of AssociationEntities.

- JunctionList<>
	A Collection used to signalize that the list consists of JunctionEntities.

- Percent
	A ValueObject representing a percentage value.
